AWS CodeArtifact, CodeStar & Cloud9 — CLF-C02 Notes
These are AWS developer tools related to package management, software project management, and cloud-based development environments.
1. AWS CodeArtifact









AWS CodeArtifact
A managed artifact repository service for securely storing, publishing, and sharing software packages and dependencies.


What problem does it solve?
Suppose your Python project needs packages such as Flask, NumPy, and Pillow. CodeArtifact can host and manage approved packages so developers and build systems can retrieve dependencies from a controlled repository.
Key features
- Stores and shares software packages.
- Supports package formats such as Python, npm, Maven, and NuGet.
- Can proxy public package repositories, helping teams cache and control access to dependencies.
- Integrates with IAM for access control.
- Works with CI/CD tools such as CodeBuild.
Example: CodeBuild downloads approved Python dependencies from CodeArtifact before running tests.
Exam clue: Securely store and distribute software packages or dependencies → CodeArtifact.
2. AWS CodeStar









AWS CodeStar was a project-management and development service that helped teams create, manage, and build software projects on AWS.


What did CodeStar do?
- Set up software development projects.
- Integrated source control, builds, and deployment pipelines.
- Provided project dashboards and team access management.
- Helped developers get a CI/CD workflow running quickly.
Example: A team could create a project and get a starting development workflow using AWS development tools.
Current status — important for your notes
AWS discontinued the ability to create or view CodeStar projects on July 31, 2024. Existing resources created by CodeStar, such as repositories and pipelines, continue to function. AWS CodeStar Connections was not discontinued with the CodeStar project service.

Don't confuse these names:
- AWS CodeStar: Former project setup and management service.
- AWS CodeConnections: Connects AWS services, such as CodePipeline, to external repositories such as GitHub and Bitbucket. It was formerly called AWS CodeStar Connections.

3. AWS Cloud9









AWS Cloud9
A cloud-based IDE (Integrated Development Environment) that lets developers write, run, debug, and test code through a web browser. It includes a code editor and terminal. 

AWS Cloud9





Key features
- Browser-based code editor.
- Built-in terminal.
- Debugging and code completion.
- Support for multiple programming languages.
- Integration with AWS services and development workflows.
- Collaborative coding capabilities.
Example
You want to write a Python script that interacts with Amazon S3 without setting up a full development environment on your local computer. Cloud9 historically let you edit the script in a browser and execute it in a connected cloud environment.
Important current status
AWS Cloud9 is no longer available to new customers, effective July 25, 2024. Existing customers can continue using it.
